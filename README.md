# ☕ Velvet Roast — Craft Cortado Companion

**Velvet Roast** is an interactive brewing assistant engineered for dark roast coffee lovers who crave high intensity, zero sourness, and velvety chocolate warmth. Created via vibe coding during **DevFest Baku 2026**.

---

## ✨ Key Features

- **Scaled Dosing & Ingredient Ratios:** Dynamic coffee and liquid ratio calculations based on selected equipment (Moka pot / Espresso) and servings.
- **Pantry Customizer:** Fine-tune cocoa intensity, nut profiles (hazelnut, pecan, almond), sweetness, and spice additions.
- **Step-by-Step Brew Assistant:** Visual countdown timer and step-by-step extraction instructions.
- **Brew Journal & Cloud Sync:** Save custom recipes locally with Firebase Firestore sync across devices.
- **Zero-Bitterness Extraction Science:** Built-in dial-in diagnostic tips and flavor balancing guide.
- **Recipe Visualization & Sharing:** Formatted emoji export for sharing brews instantly.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Icons:** Lucide React
- **Backend & Auth:** Firebase (Authentication & Firestore)
- **Environment:** Google AI Studio
